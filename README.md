# Robotic Arm Waste Segregator 🤖

This is my first prototype project as a 7th grader, where I built a robotic arm that uses Arduino UNO Q and OpenCV to sort objects by color.  

## Features
- Color detection using OpenCV (HSV thresholding).
- WiFi communication between PC and Arduino UNO Q.
- Servo‑based robotic arm for sorting.
- First prototype at a complex level.

## Contents
- Arduino code for servo control.
- Python scripts for vision + communication.
- Block diagram and circuit schematic.
- Notes on challenges, learnings, and future improvements.

## Future Improvements
- Add onboard camera to remove PC dependency.
- Upgrade to material detection using AI.
