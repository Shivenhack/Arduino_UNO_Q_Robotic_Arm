# Arduino_UNO_Q_Robotic_Arm
This is my first robotics project with the Arduino UNO Q!
My robot is a 4 servo robotic arm that can sort stuff based on colour.
It uses OpenCV to detect colours and puts the red on the left side and the blue stuff on the right side!
